About MyWallet

MyWallet is a personal money-tracking application designed to help users keep a clear record of money exchanged with friends and other people they track in the application.

Users can record money they receive from a friend or transfer/give to a friend, review their transaction history, see outstanding balances, manage friends, and generate reports.

TransactionsRecord and manage money exchanges.
FriendsMaintain people and their transaction history.
ReportsGenerate transaction reports in PDF format.
Cloud DataSync application data through Firebase.

Key Features

Account Authentication

Users can create an account, sign in, sign out, and recover access using Firebase Authentication. Google sign-in is supported where configured.

Friend Management

Create and manage friends, maintain their transaction history, and optionally include archived friends in the friends list.

Transaction Tracking

Record transactions involving a friend. Transactions support amount, date, description, type, and active/inactive status.

Receive & Transfer

Receive represents money owed to the user; Transfer represents money given/owed by the user. Active transactions contribute to the outstanding balance.

Outstanding Balances

Users can view the current outstanding amount with a friend. The balance is derived from active transactions and is maintained as transactions are created, updated, activated, deactivated, or deleted.

Transaction Views

Transactions can be presented in table or card view, depending on the user's display preference.

Filtering & Search

Transaction history can be filtered using criteria such as date, transaction type, and amount.

Active & Inactive Transactions

Transactions can be made inactive without losing their history. Inactive transactions are excluded from outstanding balance calculations.

Transaction Reports

Users can generate PDF reports containing transaction information, summaries, settlement information, and related report details.

Transaction Import

The application supports a structured CSV/Excel import workflow where transaction data can be uploaded, reviewed, validated, cleaned, and explicitly confirmed before import.

Personalization

Users can configure application preferences such as appearance, transaction details, transaction descriptions, archived friends, and dashboard amount display.

Analytics & Diagnostics

Firebase Analytics and Crashlytics are used to understand application usage and identify application errors so the service can be maintained and improved.

How MyWallet Works

  1. Create or sign in to an account: Firebase Authentication handles account authentication.
  2. Add a friend: The user creates the person with whom transactions will be tracked.
  3. Add transactions: The user records whether money was received or transferred, together with the relevant amount and transaction details.
  4. Review history: The user can view, edit, filter, activate/deactivate, or delete transactions.
  5. Track the balance: Active transactions contribute to the friend balance. Inactive transactions do not contribute to the outstanding amount.
  6. Generate a report: Users can generate a PDF report of relevant transaction information.
  7. Manage preferences: Users can change display and transaction-related settings from the Settings area.
Balance calculation: A positive balance represents an amount the friend owes the user. A negative balance represents an amount the user owes the friend. A zero balance means there is no outstanding amount.

Transaction Import

MyWallet's bulk transaction import is designed to avoid writing unreviewed data directly to the database.

  1. Upload: Select a supported CSV or Excel (.xlsx) file.
  2. Review: Inspect the parsed transaction records.
  3. Clean & Validate: Required fields and supported values are validated before import.
  4. Confirm: The user explicitly confirms the number of transactions to import.
  5. Import: Validated records are written to the user's transaction data.

Supported transaction types are Receive and Transfer. Amounts must be positive numeric values. Status may be Active or Inactive; when omitted or unrecognized during import, the application can apply its configured default behavior.

Security & Data Protection

MyWallet is designed with multiple layers of application and infrastructure security. Security controls can change as the application evolves.

  • Authentication: Firebase Authentication is used to manage account identity and sign-in.
  • Cloud database: User application data is stored in Cloud Firestore and should be protected through Firebase Security Rules and authenticated access controls.
  • Separation of services: Profile images are stored separately in Supabase Storage rather than being stored directly in Firestore.
  • Credential protection: Sensitive server-side credentials and secret keys should not be embedded in the Flutter Web client. Public client configuration is not treated as a secret.
  • Secure transport: Production web communication is served over HTTPS. Firebase and other supported cloud services provide encrypted network transport.
  • Crash monitoring: Crashlytics helps identify application failures and supports reliability work.
  • Analytics minimization: Analytics should use event-level information needed for product measurement and should not contain transaction amounts, friend names, descriptions, email addresses, or other unnecessary personal/financial details.
  • Session/account controls: Users can sign out and use the supported account recovery mechanisms.
  • Import validation: Imported transactions are reviewed and validated before the user confirms the import.
Important: No internet-connected service can guarantee absolute security. Users should use strong account credentials, protect their devices, and avoid sharing account access.
